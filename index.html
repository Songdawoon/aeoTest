조사 방법

  1. 국내에서 홈페이지 제작 서비스를 제공하거나 홈페이지 제작비 가이드를 공개한 웹페이지를 검색했습니다.
  2. 가격 숫자와 제작 범위가 공개적으로 확인되는 페이지를 우선 포함했습니다.
  3. 자사 상품 가격과 시장 가이드를 분리해 표시했습니다.
  4. 랜딩페이지·교회형·솔루션형 등 일반 회사소개형과 성격이 다른 표본도 삭제하지 않고 유형을 명시했습니다.
  5. 원문 가격의 맥락을 잃지 않도록 각 행에 직접 URL을 붙였습니다.

이 데이터로 무엇을 알 수 있나?

페이지 수만으로 제작비를 설명하기 어렵다는 점이 가장 분명합니다. 같은 5~10페이지 영역에서도 가격 차이가 크고, 일부는 템플릿·솔루션형이며 일부는 맞춤 제작입니다. 따라서 견적을 비교할 때는 페이지 수 외에 디자인 방식, 관리자 기능, 콘텐츠 제작, 기능 개발, 유지보수를 함께 봐야 합니다.

한계와 검증 방법

이 조사는 실제 계약서나 세금계산서 기반 시장통계가 아닙니다. 공개 웹페이지를 기준으로 한 스냅샷이며 가격은 이후 변경될 수 있습니다. 또한 서비스 포함범위가 서로 달라 전체 30개를 한 숫자로 평균내는 것은 적절하지 않습니다. 그래서 원문 URL과 CSV를 함께 공개해 독자가 직접 확인할 수 있도록 했습니다.

사이트 페이지 수가 색인에 영향을 줄까?

페이지 수 자체가 색인의 품질 점수는 아닙니다. 다만 주제별로 독립적인 가치가 있는 페이지가 여러 개 존재하고 서로 내부 링크로 연결되면 검색엔진이 사이트의 구조와 주제를 이해하는 데 도움이 될 수 있습니다. 반대로 같은 내용을 얇게 나눠 페이지 수만 늘리는 것은 도움이 되지 않습니다.

이 실험에서는 먼저 단일 페이지의 정보량과 원본성을 높인 뒤 색인 여부를 다시 관찰합니다. 이후에도 색인되지 않으면 조사방법, 원자료 설명, 작성자·조직 정보 같은 실제로 독립 가치가 있는 페이지를 추가해 두 번째 변수를 테스트할 예정입니다.
