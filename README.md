# AI Citation Experiment #001

목표: `2026 홈페이지 제작비용` 질문에서 ChatGPT Search, Google/Gemini, Perplexity가 이 사이트를 검색 후보 또는 인용 출처로 선택하는지 실험합니다.

## 현재 구성
- `index.html` — 실험용 리서치 페이지
- `robots.txt` — OAI-SearchBot, PerplexityBot, Googlebot 접근 허용
- `test-queries.txt` — 반복 측정용 고정 질문 10개

## 배포 후 해야 할 일
1. Vercel에 `main` 브랜치 연결
2. 공개 URL 확인
3. 실제 URL 기준으로 canonical과 sitemap 추가
4. Google Search Console에서 색인 요청
5. 동일 질문 10개를 ChatGPT, Gemini/Google AI, Perplexity에서 반복 측정

## 실험 핵심 지표
- 직접 인용 여부
- 링크 노출 여부
- 페이지 내용 반영 여부
- 함께 인용된 경쟁 출처
- 최초 인용까지 걸린 시간

주의: 이 페이지의 가격 수치는 실제 계약가 시장통계가 아니라 공개 가격 가이드 5개의 비교값입니다.
